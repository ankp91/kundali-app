# Kundali App

Vedic birth chart generator with AI interpretation and learning curriculum.

## Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
cp .env.example .env  # add ANTHROPIC_API_KEY
./start.sh
```

### Frontend
```bash
cd frontend
npm install
cp .env.local.example .env.local
./start.sh
```

Open http://localhost:3000
